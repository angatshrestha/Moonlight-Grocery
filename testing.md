# Week 10 — Testing

## Expected Deliverable
Ensure system quality through testing activities.

## Activities Completed
- Performed unit testing on individual system functions.
- Conducted integration testing to verify interaction between modules.
- Completed manual testing by navigating through the application and validating user workflows.

## Critical Test Cases
1. User login with valid credentials.
2. User login with invalid credentials.
3. Display products from the database.
4. Add products to the shopping cart.
5. Update cart quantities.
6. Remove products from the cart.
7. Complete checkout process.
8. Store order details in the database.
9. Verify database connectivity.
10. Test navigation between pages.

## Bugs Identified
- CSS styling issues on some pages.
- Database connection errors during configuration.
- Empty content displayed on certain pages.
- Broken links or incorrect file paths.
